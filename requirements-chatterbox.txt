# chatterbox-turbo wheels, deliberately kept out of requirements-heavy-cuda.txt.
# Rationale (full version in scripts/heavy-deps-cuda.in): both packages declare
# dependency metadata that is either unsatisfiable against this image's pins or
# drags dev tooling into the runtime image, and Dockerfile.cuda installs
# --no-deps from the compiled file, so anything the resolver emits gets
# installed. Both wheels are pure-python; every module they import is already
# provided by requirements-heavy-cuda.txt.
#
#   chatterbox-tts — metadata hard-pins torch==2.6.0 / transformers==5.2.0
#     (image ships 2.9.1 / 4.57.3) and pulls gradio.
#   s3tokenizer    — declares pre-commit as a RUNTIME dependency, which pulls
#     virtualenv / distlib / nodeenv / identify / cfgv.
#
# Hashes are the PyPI wheel sha256 for the pinned version. Bump both the
# version and the hash together.

    --hash=sha256:c9e93b1892a124a2c4d958ab53610a1b4433fcb4172056e2f2bd3c09cfe249a6
